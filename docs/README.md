# Documentação do ObraAtiva

- `audits/`: diagnósticos, inventários e planos resultantes de auditorias.
- `plans/`: planos de evolução que ainda exigem execução controlada.
- `distribution/`: publicação Android e informações de lojas.
- `standards/`: convenções técnicas para manutenção consistente do projeto.
- `design-sources/`: imagens de referência que não fazem parte do aplicativo publicado.
  - `design-sources/legacy-unused/`: referências antigas retiradas dos ativos públicos, preservadas apenas para consulta e rollback.

Arquivos de documentação não contêm dados de empresas e não entram no pacote de produção.
