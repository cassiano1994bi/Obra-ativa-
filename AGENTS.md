# Regras obrigatórias do projeto Controle de Obra

Leia este arquivo completamente antes de analisar, editar, testar ou publicar qualquer alteração neste projeto.

## Regra principal definida pelo proprietário

- Altere somente a função, tela ou comportamento solicitado no comando atual.
- Nunca oculte, remova, filtre, substitua, arquive ou deixe de exibir informações, obras, clientes, funcionários, botões, abas, registros ou funções existentes sem autorização explícita do proprietário.
- Uma informação com valor zero ou sem movimentação também deve continuar visível, salvo ordem explícita em contrário.
- Não interprete uma solicitação de organização visual ou correção de cálculo como autorização para eliminar ou esconder conteúdo.
- Preserve todos os dados atuais da empresa. Dados reais da empresa somente podem ser alterados pelo proprietário.
- Testes não podem criar, editar ou excluir dados reais. Use leitura, dados fictícios ou cópia isolada.
- Nunca copie, reutilize ou transcreva em testes, prévias, relatórios, capturas, documentação ou arquivos locais qualquer dado visto em uma conta real. Isso inclui nomes, e-mails, obras, clientes, funcionários, quantidades, presenças, pagamentos, saldos, valores financeiros e demais informações da empresa.
- Dados de teste devem ser claramente artificiais, identificados como `TESTE` ou `FICTÍCIO` e nunca podem ser derivados, aproximados ou coincidir propositalmente com valores exibidos no aplicativo real. Se houver dúvida se uma informação é real, trate-a como real e não a utilize.
- É proibido entrar em uma conta real ou executar testes usando usuário, empresa ou registros reais. Todo teste funcional deve usar uma página isolada e sem conexão com Supabase, nuvem, banco ou armazenamento da aplicação.
- Arquivos das pastas de testes, fixtures, simulações e prévias locais nunca podem ser enviados na publicação. Antes de publicar, confirme que nenhum dado ou arquivo de teste está incluído no pacote autorizado.
- Publicar significa atualizar somente os arquivos autorizados do aplicativo. Uma publicação nunca autoriza inserir, importar, restaurar, sincronizar, migrar ou modificar dados de nenhuma empresa.
- Antes de concluir, compare a área afetada com o comportamento anterior e confirme que nenhuma função ou informação não solicitada desapareceu.
- Não publique online sem autorização explícita do proprietário para publicar aquela atualização.
- Toda publicação deve atualizar somente os arquivos e funções autorizados do aplicativo. Nunca importe, substitua, restaure, migre, apague ou altere dados da empresa durante uma publicação.
- Antes de qualquer publicação, faça uma verificação explícita de que: (1) os dados das empresas permanecem intocados; (2) nenhum dado real foi copiado para o código; (3) nenhum arquivo de teste será publicado; e (4) somente os arquivos autorizados serão enviados.
- Se uma alteração exigir mexer em outra função, dado ou regra fora do pedido, pare e peça autorização antes de continuar.

## Entrega obrigatória

Ao finalizar, informe claramente:

1. O que foi alterado.
2. O que foi preservado.
3. Como a alteração foi testada.
4. Se está apenas na prévia local ou se foi publicada.
